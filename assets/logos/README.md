# Logo sources

UCSB, UNC, and Harvard: copied unchanged from the user-provided local
TAPS-DLM.github.io/logo directory.

UW–Madison: official full-color digital crest from
https://brand.wisc.edu/resource/crest-only-logo-for-web-digital-use-full-color/
(download: https://brand.wisc.edu/content/uploads/2023/10/uw-crest-color-web-digital.zip).

Hugging Face: copied from the manuscript assets/hf-logo.svg.

arXiv: official SVG used by the supplied reference website:
https://arxiv.org/static/browse/0.3.4/images/arxiv-logomark-small-white.svg
The website displays this vector mark in black using a CSS filter.
