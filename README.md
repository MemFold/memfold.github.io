# MemFold project website

A standalone static placeholder website for GitHub Pages. No build dependencies are required.

Publish the contents of this directory at the root of the website repository.
In Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**.
Future pushes to `main` will update the site automatically.

Website: https://MemFold.github.io

Repository: https://github.com/MemFold/memfold.github.io

Edit `index.html` to replace the placeholder with the full project page.
