MemFold:Learning Compact Soft Memory for Long-Context Personalization via On-Policy Optimization

Small memory. Personal answers.

A useful memory should change what an assistant says. We train a reader to turn a compact representation of a user’s history into answers that put that history to use.

01 / THE IDEA

Learning to use what we remember

Over many conversations, a user reveals preferences, revises plans, and adds constraints. A personalized assistant needs to identify which details still matter and use them in its next answer.

Keeping the history as text makes the reader’s input grow with every interaction. Compressing it into a fixed set of vectors bounds that input, but introduces a training problem: reconstructing text or imitating reference answers does not directly optimize the responses the reader generates on its own.

MemFold trains the reader to put compact memory to use. The reader generates responses from soft memory and learns from two signals: task rewards that evaluate its answers, and token-level guidance from a frozen teacher that reads the corresponding textual memory.

02 / HOW IT WORKS

From interaction history to a useful memory

A writer first extracts query-relevant information from the history available at the time of the question. A Perceiver-style compressor maps this textual memory into K continuous vectors. The reader then answers from the query and these vectors, using a fixed memory interface even as the history grows.

Supervised initialization teaches the reader to consume this interface. On-policy training then improves how it uses memory, combining two signals on the same student-generated responses (Fig. 1):

  1. Reward the outcome. Group-relative policy optimization (GRPO) uses task rewards to improve the reader’s responses.
  2. Guide individual tokens. A frozen textual-memory teacher re-scores the student’s sampled tokens. A detached confidence gate weights this on-policy distillation signal.

The teacher scores the student’s tokens without generating a separate answer. It adds forward passes during training and is removed at inference. The memory budget limits the reader’s input; constructing that memory still requires processing the history.

03 / THE RESULTS

Evaluating long-context personalization

We evaluate MemFold with three Qwen backbones on PersonaMem-32K and PersonaMem-128K, then test direct transfer to PrefEval and LongMemEval. It achieves the highest accuracy in the reported comparison for each backbone and benchmark, with a tie on PrefEval for Qwen2.5-7B.

Transfer beyond the training dataset

For PrefEval, we use checkpoints trained on PersonaMem-32K. For LongMemEval, we use checkpoints trained and selected on LoCoMo. Neither setting includes target-dataset training. Together, they test personalization transfer and broader memory capabilities such as multi-session reasoning and knowledge updates.

The weighted-average token-equivalent cost is lower than Full Text for all three backbones. This saving does not hold in every setting: memory construction adds overhead on short-history PrefEval, and some other individual comparisons also use more tokens.

04 / LEARNING EFFICIENTLY

Learning from the reader’s own responses

With Qwen2.5-3B-Instruct on PersonaMem-32K, MemFold improves accuracy more rapidly with optimizer updates and reaches comparable accuracy with fewer student rollouts (Fig. 2). The reward and distillation objectives reuse the same responses.

Where does the improvement come from?

In the component ablation, GRPO contributes most of the task gain. Adding OPD improves mean accuracy from 71.9 to 75.4 on PersonaMem-32K and from 86.9 to 87.9 on PersonaMem-128K. Reader initialization is also essential: the reader must first learn to consume soft memory.

These ablation scores average 16 sampled responses at temperature 1.0, so they should be read separately from the main results. The rollout curves also exclude the additional cost of initialization and teacher forward passes.

05 / INSIDE THE MEMORY

Examining the memory interface

We test the interface in two ways: varying its capacity and changing the memory supplied to the reader. In Fig. 3A, accuracy peaks at 256 vectors on both PersonaMem settings. Increasing the budget to 512 does not improve accuracy under this training recipe.

Replacing the matched memory with shuffled or null memory causes substantial accuracy drops (Fig. 3B). The reader therefore relies on instance-specific memory. This intervention does not identify which facts the vectors preserve or how they encode changes in preferences.

What does the memory budget cost?

Changing K from 64 to 512 has little effect on end-to-end token-equivalent cost (Fig. 4). The variation is below one percent on PersonaMem-128K, where reading the history to construct textual memory accounts for nearly all of the per-instance cost.

The textual-memory teacher scores below the final student on task accuracy in Fig. 3B. This is consistent with its training role: it supplies bounded token-level guidance while GRPO drives most of the task-level improvement.

06 / A PERSONAL ANSWER

What personalization changes in an answer

A generally useful answer can still miss a user’s preference. In Fig. 6, the history implies that the user dislikes wearable technology. Asked how to monitor fitness progress, GRPO and OPSD both recommend wearables. MemFold instead suggests a journal, body measurements, and a progress photo log.

The displayed preference summarizes the interaction history and is not given explicitly to the models. This single example illustrates a personalization failure; it does not measure how often that failure occurs or establish an end-to-end efficiency gain.

07 / TAKEAWAYS

Toward memory that supports better answers

MemFold makes compact memory useful by training the reader on its own responses. Task rewards improve answer quality, and a frozen textual-memory teacher adds complementary guidance. The experiments support this approach across the tested history lengths, backbones, and transfer settings.

Open questions include which facts survive compression, how readers resolve changing preferences, and how to reduce memory-construction cost. Answering them will help connect compact representations to more reliable personalization.
